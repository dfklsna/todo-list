# TodoList

HTML, CSS, 순수 JavaScript로 만든 간단한 할 일 관리 웹 애플리케이션입니다. 별도의 프레임워크나 빌드 과정 없이 브라우저에서 바로 실행할 수 있으며, DOM 생성·이벤트 처리·클래스 제어 등 JavaScript의 기본 동작을 연습하는 프로젝트입니다.

## 주요 기능

- 입력한 할 일을 목록에 추가
- 입력값 앞뒤 공백 자동 제거
- 빈 내용을 제출하면 경고창을 표시하고 입력창에 다시 포커스
- `완료` 버튼으로 완료 상태를 켜고 끄기
- 완료된 항목에 취소선 스타일 적용
- `삭제` 버튼으로 원하는 항목 제거
- 사용자 입력을 `textContent`로 출력해 HTML 태그가 실행되지 않도록 처리

## 사용 방법

1. 입력창에 할 일을 작성합니다.
2. `추가` 버튼을 누르거나 Enter 키를 입력합니다.
3. 끝낸 일은 `완료` 버튼을 눌러 완료 상태로 표시합니다.
4. 필요 없는 항목은 `삭제` 버튼으로 제거합니다.

## 실행 방법

빌드와 패키지 설치가 필요하지 않습니다.

### 방법 1: 파일 직접 실행

저장소를 내려받은 뒤 `index.html`을 브라우저로 엽니다.

```bash
git clone https://github.com/dfklsna/todo-list.git
cd todo-list
```

그다음 파일 탐색기에서 `index.html`을 더블클릭하면 됩니다.

### 방법 2: 로컬 웹 서버 실행

Python이 설치되어 있다면 프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다.

## 프로젝트 구조

```text
todo-list/
├── index.html   # 페이지 구조와 할 일 입력 폼
├── style.css    # 레이아웃, 버튼, 완료 상태 스타일
├── app.js       # 할 일 추가·완료·삭제 로직
└── README.md    # 프로젝트 설명과 실행 방법
```

## 동작 구조

```text
폼 제출
  └─ 기본 새로고침 방지
      └─ 입력값 trim 및 빈 값 검사
          └─ li, span, 버튼 DOM 생성
              ├─ 완료: done 클래스 토글
              └─ 삭제: 현재 li 제거
```

`app.js`는 폼의 `submit` 이벤트에서 `event.preventDefault()`를 호출해 페이지 새로고침을 막습니다. 유효한 입력값은 `addTodo()` 함수로 전달되며, 함수 안에서 목록 항목과 완료·삭제 버튼을 동적으로 생성합니다.

## 사용 기술

- HTML5
- CSS3
- Vanilla JavaScript
- DOM API와 이벤트 리스너

## 구현 포인트

- `<script defer>`를 사용해 HTML 파싱 후 JavaScript가 실행되도록 구성했습니다.
- `classList.toggle("done")`으로 완료 상태를 간단히 전환합니다.
- `Element.remove()`로 선택한 항목만 삭제합니다.
- `innerHTML` 대신 `textContent`를 사용해 입력 문자열을 그대로 표시합니다.
- `max-width`와 유동 너비를 함께 사용해 작은 화면에서도 기본 레이아웃이 유지됩니다.

## 현재 한계

- 브라우저 저장소나 서버를 사용하지 않으므로 새로고침하면 목록이 초기화됩니다.
- 할 일 수정, 필터, 정렬, 마감일, 우선순위 기능은 제공하지 않습니다.
- 자동화 테스트는 포함되어 있지 않습니다.
